- CVE-2018-14574: Open redirect possibility in ``CommonMiddleware`` ================================================================= [6f484351]
- Django 1.11.15 fixes a security issue in 1.11.14. [3e0281bb]
- If the :class:`~django.middleware.common.CommonMiddleware` and the :setting:`APPEND_SLASH` setting are both enabled, and if the project has a URL pattern that accepts any path ending in a slash (many content management systems have such a pattern), then a request to a maliciously crafted URL of that site could lead to a redirect to another site, enabling phishing and other attacks.
