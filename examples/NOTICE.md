# Third-party notices for the example bundles

The bundles under `examples/` (`memos-bundle`, `django-bundle`, `django-models-bundle`
and `django-shards`) are generated by Dossier from those projects' public sources and
contain verbatim excerpts of their documentation and source code. Each bundle's facts
quote the upstream text; the licenses below cover those excerpts.

These notices apply to the repository only. The example bundles are not shipped in
release archives; the notices for the components that are shipped are in
[`THIRD-PARTY-NOTICES.md`](../THIRD-PARTY-NOTICES.md).
