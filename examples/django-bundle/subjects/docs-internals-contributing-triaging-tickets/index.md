- [59c569ff] 5. Check the documentation. Is the documentation understandable? Does it provide the information the reader needs at that moment? Does it read well? Is it consistent with the documentation before and after it? See :ref:`build-documentation-locally`.

Also ask yourself, is the scope of the change appropriate? Are things named appropriately? Renaming things is slow and challenging in Django, so we should try to get it right from the start.
