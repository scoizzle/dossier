# Security policy

## Supported versions

Only the latest release and the current `main` branch receive security fixes.

## Reporting a vulnerability

Report vulnerabilities privately to the maintainer through GitHub. Do not open a public issue or pull request that describes the problem.

Please include:

- what the issue is and which component it affects (the CLI, `dossier mcp`, `dossier serve`, the store, or publish and import);
- the version or commit you tested, and your operating system;
- steps or a minimal input that reproduces it;
- the impact you expect, and any suggested fix.

Reports are handled on a best-effort basis by a single maintainer.
