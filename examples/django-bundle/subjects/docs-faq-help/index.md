- Detailed instructions on how to handle a potential bug can be found in our :ref:`Guide to contributing to Django <reporting-bugs>`. [2d95a133]
- Due to the sensitive nature of security issues, we ask that if you think you have found a security problem, *please* don't post a message on the forum, the Discord server, IRC, or one of the public mailing lists. Django has a :ref:`policy for handling security issues <reporting-security-issues>`; while a defect is outstanding, we would like to minimize any damage that could be inflicted through public knowledge of that defect. [7faed506]
